## 3. Новая система эффектов

### Старая система:
```javascript
effects: { 
  items: { "apple": 5 }, 
  relationships: { "character1": 10 } 
}
```

### Новая система:
```javascript
effects: [
  { id: "effect_1", type: "item", targetId: "apple", value: 5 },
  { id: "effect_2", type: "relationship", targetId: "character1", value: 10 }
]
```

### Преимущества:
- **Четкое разделение**: Каждый эффект имеет свой тип (предмет/отношения)
- **Удобное редактирование**: Отдельные поля для ID и значения
- **Валидация**: Автоматическая проверка корректности данных
- **Визуальные индикаторы**: Цветные бейджи для разных типов эффектов

### Интерфейс:
- Кнопки "Добавить предмет" и "Добавить отношения"
- Выпадающие списки с доступными предметами и персонажами
- Выпадающий список для требуемых предметов
- Возможность удаления отдельных эффектов
- Автоматическая загрузка данных из `items.json`

## 4. Система важных выборов с localStorage

### Функциональность:
- **Автоматическое сохранение**: При установке флага "важный выбор" и сохранении сцены данные автоматически сохраняются в localStorage
- **Уникальные ID**: Каждый важный выбор имеет уникальный идентификатор
- **Привязка к главе**: Выборы сохраняются отдельно для каждой главы
- **Подтягивание значений**: При установке требований доступны уже существующие выборы из выпадающего списка

### Логика работы:
1. Пользователь устанавливает флаг "важный выбор" для варианта выбора
2. Заполняет ID выбора и значение
3. При сохранении сцены важный выбор автоматически сохраняется в localStorage
4. При установке требований к другим выборам доступен список сохраненных важных выборов

### Утилиты (`importantChoicesUtils.js`):
- `saveImportantChoice()` - сохранение выбора
- `loadImportantChoices()` - загрузка выборов главы
- `removeImportantChoice()` - удаление выбора
- `clearImportantChoices()` - очистка всех выборов главы
- `exportImportantChoices()` - экспорт в JSON
- `importImportantChoices()` - импорт из JSON

## 5. Улучшенная работа с предметами

### Автоматическая загрузка:
- Данные предметов загружаются из `items.json`
- Структурированный доступ ко всем категориям предметов
- Отображение названий предметов в выпадающих списках

### Обновленная структура предметов:
- **Удалена категория materials** - больше не используется
- **Добавлена категория gifts** - 18 предметов для подарков через диалоги
- **Обновлена категория special** - 56 предметов для квестов (недоступны в магазине)
- **Подарки (gifts)** - можно получать через диалоги и продавать за золото
- **Специальные предметы (special)** - используются только в квестах

### Логика ротации магазина:
- **Всегда доступны**: расходуемые предметы, ключи, подарки, одежда
- **Ротация каждые 7 дней**: только питомцы (до 8 случайных питомцев)
- **Специальные предметы**: недоступны в магазине (только через квесты)

### Обновленные типы предметов:
- **consumable** - расходуемые предметы (зелья, еда)
- **gift** - подарки (новый тип, оранжевый цвет) - доступны в магазине
- **special** - квестовые предметы (фиолетовый цвет) - недоступны в магазине
- **pet** - питомцы (оранжевый цвет)
- **clothing** - одежда (розовый цвет)
- **chest** - сундуки (оранжевый цвет)
- **key** - ключи (серый цвет)

### Структура данных:
```javascript
{
  "consumable": {
    "apple": { "id": "apple", "name": "Яблоко", ... },
    "potion": { "id": "potion", "name": "Зелье", ... }
  },
  "gifts": {
    "apple": { "id": "apple", "name": "Яблоко", "type": "gift", ... },
    "chocolate": { "id": "chocolate", "name": "Шоколад", "type": "gift", ... }
  },
  "special": {
    "ancient_tablet": { "id": "ancient_tablet", "name": "Древняя табличка", "type": "special", ... }
  }
}
```

## 7. Использование

### Редактирование сцены:
1. Откройте редактор сцен
2. Перейдите на вкладку "Выборы"
3. Создайте новый выбор или отредактируйте существующий
4. Добавьте эффекты через кнопки "Добавить предмет" или "Добавить отношения"
5. Установите важный выбор для сохранения в localStorage

### Управление важными выборами:
1. Установите флаг "важный выбор" для нужного варианта выбора
2. Заполните ID выбора и значение
3. Сохраните сцену - важный выбор автоматически сохранится в localStorage
4. При установке требований к другим выборам выберите из списка сохраненных важных выборов

### Требования к важным выборам:
1. При установке требования выберите из списка сохраненных выборов
2. Укажите требуемое значение
3. Оставьте поле пустым для null (использование один раз)

## 9. Обновление структуры предметов

### Изменения в items.json:
1. **Удалена категория materials** - больше не используется в игре
2. **Добавлена категория gifts** - 18 предметов для подарков через диалоги
3. **Обновлена категория special** - 56 предметов для квестов (недоступны в магазине)
4. **Обновлена секция types** - удален тип "material", добавлен тип "gift" с оранжевым цветом

### Обновление логики ротации магазина:
1. **Упрощена ротация** - теперь влияет только на питомцев
2. **Постоянный ассортимент** - расходуемые, ключи, подарки, одежда всегда доступны
3. **Случайные питомцы** - до 8 питомцев меняются каждые 7 дней
4. **Детерминированная ротация** - использует номер недели как seed для предсказуемости

### Обновление системы ценообразования питомцев:
1. **Пересмотрены все цены** - 85 питомцев обновлены
2. **Базовая цена по редкости** - четкая градация стоимости
3. **Mythical и Legendary за драгоценные камни** - как требовалось
4. **Множители по способностям** - stat +1/+2/+3/+4/+5 отличаются по стоимости
5. **Самые дорогие способности** - reroll и cube как требовалось

### Новая система ценообразования питомцев:
1. **Базовая цена по редкости**:
   - Common: 100 монет
   - Rare: 300 монет
   - Mythical: 50 драгоценных камней
   - Legendary: 100 драгоценных камней

2. **Множители по способностям**:
   - Stat +1 = 1.0x, +2 = 1.5x, +3 = 2.0x, +4 = 2.5x, +5 = 3.0x
   - Relation +10 = 1.0x, +15 = 1.2x, +20 = 1.4x, +25 = 1.6x, +35 = 1.8x, +50 = 2.0x
   - Reroll 1 = 2.0x, Reroll 2 = 2.5x
   - Cube 1 = 3.0x, Cube 2 = 4.0x (самые дорогие способности)
   - Money +10 = 1.5x, +20 = 1.8x, +30 = 2.0x
   - Price 10 = 1.5x, 20 = 1.8x, 30 = 2.0x

3. **Примеры цен**:
   - Слайм (common, relation +10): 100 монет
   - Фея (mythical, stat +3): 100 драгоценных камней
   - Дракон (legendary, cube +2): 400 драгоценных камней
   - Тень (rare, reroll +2): 750 монет

### Новые типы предметов:
- **gifts** - подарки, получаемые через диалоги, можно продавать за золото
- **special** - специальные предметы для квестов, недоступны в магазине
