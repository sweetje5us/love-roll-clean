# Исправление Font Awesome иконок в Cordova

## Проблема
В Cordova версии приложения Font Awesome иконки не отображались, так как CDN недоступен в WebView.

## Решение
Установлена локальная версия Font Awesome через npm пакет.

## Что сделано

### 1. Установка Font Awesome
```bash
npm install @fortawesome/fontawesome-free
```

### 2. Копирование файлов
- **CSS файлы:** `public/static/css/` (включая `all.css`)
- **Web шрифты:** `public/static/webfonts/` (включая `.woff2` файлы)

### 3. Обновление скриптов сборки
- Изменен путь к Font Awesome с CDN на локальный: `./static/css/all.css`
- Добавлено копирование Font Awesome файлов в Cordova проект

## Файлы Font Awesome

### CSS файлы:
- `all.css` - полная версия (107KB)
- `all.min.css` - минифицированная версия (72KB)
- `solid.css`, `regular.css`, `brands.css` - отдельные стили

### Web шрифты:
- `fa-solid-900.woff2` - сплошные иконки
- `fa-regular-400.woff2` - обычные иконки  
- `fa-brands-400.woff2` - брендовые иконки
- `fa-v4compatibility.woff2` - совместимость с v4

## Использование

### Запуск с исправленными иконками:
```bash
./setup-android-debug-final-optimized.bat
```

### Проверка иконок:
1. Все иконки должны отображаться корректно
2. Логотип игры должен быть виден
3. Кнопки должны иметь иконки
4. UI элементы должны отображаться правильно

## Преимущества локальной версии

✅ **Надежность** - иконки всегда доступны
✅ **Скорость** - нет зависимости от интернета
✅ **Совместимость** - работает в любом WebView
✅ **Полнота** - все иконки Font Awesome доступны
