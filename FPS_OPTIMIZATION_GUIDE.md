# 🎯 Оптимизация под разную частоту экрана (60/90/120 Hz)

## Проблема
Мобильное приложение было привязано к конкретной частоте кадров (60 FPS), что вызывало проблемы на устройствах с 90Hz и 120Hz экранами:
- Игры работали слишком быстро на высокочастотных экранах
- Анимации выглядели по-разному на разных устройствах
- Фиксированные интервалы setTimeout/setInterval

### 2. ⚡ Адаптивные игровые циклы
**Файл:** `src/components/ui/PetMiniGameModal.js`

**До (проблемное):**
```javascript
// Фиксированное движение - 2 пикселя за кадр
pipes.current = pipes.current.map(pipe => ({ ...pipe, x: pipe.x - 2 }));
```

**После (исправлено):**
```javascript
// Адаптивное движение с delta time
const ADAPTIVE_PIPE_SPEED = getAdaptiveSpeed(2); // базовая скорость для 60 FPS
pipes.current = pipes.current.map(pipe => ({ 
  ...pipe, 
  x: pipe.x - (ADAPTIVE_PIPE_SPEED * deltaMultiplier)
}));
```

### 3. 🎨 Адаптивные CSS анимации
**CSS переменные автоматически адаптируются:**
```css
:root {
  --refresh-rate: 120; /* автоматически определяется */
  --frame-time: 8.33ms; /* 1000/120 */
  --time-multiplier: 0.5; /* 8.33/16.67 для 120Hz */
  --base-transition: 0.075s; /* 0.15s * 0.5 */
}
```

### 4. 🔄 Адаптивные таймеры
```javascript
// Автоматическая адаптация интервалов
const adaptedInterval = getAdaptedInterval(100); // базовый интервал 100ms
setInterval(callback, adaptedInterval);
```

## Результат

### 📱 На 60Hz экранах:
- Множитель: 1.0x (базовое поведение)
- Анимации: стандартная длительность

### 📱 На 90Hz экранах:
- Множитель: 0.74x (16.67/11.11)
- Анимации: слегка быстрее для плавности

### 📱 На 120Hz экранах:
- Множитель: 0.5x (16.67/8.33)
- Анимации: в 2 раза быстрее для оптимальной плавности
