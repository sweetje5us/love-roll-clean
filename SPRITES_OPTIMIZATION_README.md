# Оптимизация спрайтов для мобильного приложения

Этот набор скриптов поможет автоматически оптимизировать спрайты для уменьшения размера мобильного приложения.

## 📋 Что делает оптимизация

- **Уменьшает разрешение изображений** с сохранением пропорций
- **Сжимает PNG файлы** с максимальным сжатием
- **Оптимизирует JPEG качество** для мобильных устройств
- **Создает резервные копии** оригинальных файлов
- **Анализирует размеры** и дает рекомендации

## 🎯 Настройки оптимизации

| Тип спрайта | Максимальный размер | Описание |
|-------------|-------------------|----------|
| Персонажи | 512x512 | Спрайты персонажей, эмоции, одежда |
| Предметы | 256x256 | Предметы, подарки, еда |
| UI элементы | 128x128 | Иконки, кнопки, интерфейс |
| Достижения | 128x128 | Значки достижений |
| Спрайты страха | 256x256 | Скелеты и другие страшные спрайты |
| Эпизоды | 512x512 | Изображения эпизодов |
| Фоны | 1024x768 | Фоновые изображения локаций |

## 🚀 Как использовать

### 1. Анализ текущего состояния

Сначала проанализируйте размеры спрайтов:

```bash
analyze_sprites.bat
```

Это покажет:
- Общий размер всех спрайтов
- Распределение по типам
- Топ самых больших файлов
- Рекомендации по оптимизации

### 2. Оптимизация спрайтов

Запустите оптимизацию:

```bash
optimize_sprites.bat
```

Скрипт:
- Создаст резервные копии в папке `sprites_backup`
- Оптимизирует все изображения
- Покажет прогресс обработки

### 3. Тестирование

После оптимизации:
1. Запустите веб-версию игры
2. Проверьте качество спрайтов
3. Убедитесь, что все выглядит хорошо

### 4. Восстановление (если нужно)

Если результат не устраивает:

```bash
restore_sprites.bat
```

Это восстановит оригинальные файлы из резервных копий.

## 📦 Требования

### Обязательные
- **Node.js** - https://nodejs.org/
- **ImageMagick** - https://imagemagick.org/script/download.php

### Установка ImageMagick

1. Скачайте ImageMagick для Windows
2. При установке отметьте "Add application directory to your system path"
3. Перезапустите командную строку

## 📁 Структура файлов

```
project/
├── optimize_sprites.js          # Основной скрипт оптимизации
├── optimize_sprites.bat         # Batch-файл для запуска
├── analyze_sprites.js           # Скрипт анализа
├── analyze_sprites.bat          # Batch-файл анализа
├── restore_sprites.js           # Скрипт восстановления
├── restore_sprites.bat          # Batch-файл восстановления
├── sprites_backup/              # Резервные копии (создается автоматически)
└── public/sprites/              # Папка со спрайтами
```

## ⚙️ Настройка параметров

Откройте `optimize_sprites.js` и измените конфигурацию:

```javascript
const CONFIG = {
    maxSizes: {
        characters: { width: 512, height: 512 },    // Измените размеры
        items: { width: 256, height: 256 },
        // ...
    },
    jpegQuality: 85,        // Качество JPEG (0-100)
    pngCompression: 9,      // Сжатие PNG (0-9)
    createBackup: true,     // Создавать резервные копии
};
```

## 🔧 Ручная оптимизация

Если нужно оптимизировать только определенные папки:

```javascript
// В optimize_sprites.js измените:
const spritesDir = 'public/sprites/characters'; // Только персонажи
```

## ⚠️ Важные замечания

1. **Всегда тестируйте** оптимизированные спрайты в веб-версии
2. **Резервные копии** создаются автоматически
3. **ImageMagick обязателен** для качественной оптимизации
4. **Процесс может занять время** при большом количестве файлов

## 🆘 Устранение проблем

### ImageMagick не найден
```
Установите ImageMagick и добавьте в PATH
```

### Ошибки при оптимизации
```
Проверьте права доступа к файлам
Убедитесь, что файлы не заблокированы
```

### Слишком большое сжатие
```
Уменьшите уровень сжатия PNG или качество JPEG
```
