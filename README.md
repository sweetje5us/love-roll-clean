# Love Roll Clean

Визуальная новелла с элементами RPG и системой отношений.

## 🎮 Особенности

- **Динамическая система эпизодов** - эпизоды загружаются напрямую из папок без дублирования данных
- **Система отношений** - развивайте отношения с персонажами
- **Важные выборы** - ваши решения влияют на сюжет
- **Система питомцев** - собирайте и развивайте питомцев
- **Магазин предметов** - покупайте одежду и аксессуары
- **Система бросков кубиков** - проверяйте характеристики персонажей

## 📝 Система эпизодов

### Добавление нового эпизода:

1. Создайте папку в `public/episodes/` с именем эпизода
2. Создайте файл `config.json` с конфигурацией эпизода
3. Добавьте эпизод в список:
   ```bash
   node scripts/add_episode.js <episode_id>
   ```

### Структура эпизода:
```
episode_name/
├── config.json     # Конфигурация эпизода
├── chapters/       # Папка с главами
├── scenes/         # Папка со сценами
└── characters/     # Папка с персонажами (опционально)
```

Подробная документация: [docs/EPISODE_SYSTEM.md](docs/EPISODE_SYSTEM.md)

## Оптимизация производительности мини-игр

### Проблема
Мини-игры (Crossy Road, Zuma, Doodle Jump, Flappy Bird) страдали от проблем производительности на мобильных устройствах, включая:
- Дерганье и нестабильный FPS
- Задержки в управлении
- Медленные анимации

### Примененные решения

#### 1. Адаптивные настройки производительности
- **Определение типа устройства**: Автоматическое определение мобильных и слабых устройств
- **Динамические настройки**: Разные параметры для разных типов устройств
- **Оптимизированные интервалы**: Уменьшенные интервалы рендеринга для плавности

#### 2. Оптимизация игрового цикла
- **DeltaTime**: Использование deltaTime для стабильной физики независимо от FPS
- **Ограничение deltaTime**: Предотвращение больших скачков времени
- **Убрано агрессивное throttling**: Удалено пропускание кадров анимации для плавности

#### 3. Hardware Acceleration
- **CSS transforms**: Принудительное включение GPU ускорения
- **will-change**: Оптимизация для браузеров
- **backface-visibility**: Дополнительные оптимизации рендеринга

#### 4. Восстановление нормальных скоростей
- **Flappy Bird**: Возвращены нормальные скорости гравитации, прыжка и труб
- **Doodle Jump**: Восстановлены стандартные параметры физики
- **Crossy Road**: Возвращена нормальная скорость препятствий
- **Zuma**: Восстановлена стандартная скорость цепочки

#### 5. Многослойный анимированный фон для Zuma
- **4 слоя фона**: Статичные слои 1, 3, 4 и анимированный слой 2
- **Анимация слоя 2**: Движение влево-вправо с отражением на границах
- **Адаптивная скорость**: 30 пикселей/сек на десктопе, 20 пикселей/сек на мобильных
- **Оптимизация для слабых устройств**: Отключение анимации фона
- **Правильные z-index**: Все игровые элементы отображаются поверх фоновых слоев

#### 6. Мягкие CSS оптимизации
- **Целевые оптимизации**: Только для игровых элементов
- **Сохранение анимаций**: Не отключаем важные анимации
- **GPU ускорение**: Включено для всех игровых элементов

#### 7. Исправление анимации печатания текста
- **Увеличена скорость**: С 8 до 80 символов в секунду
- **Убрано агрессивное пакетирование**: Символы добавляются по одному, а не пакетами по 2+
- **Исключение из CSS ограничений**: Анимация текста не подчиняется ограничениям длительности анимаций
- **Оптимизированный алгоритм**: Использование requestAnimationFrame для плавности

### Технические детали

#### Настройки производительности
```javascript
// Мобильные устройства
renderInterval: 2,        // каждые 2 кадра (30 обновлений/сек при 60 FPS)
maxDeltaTime: 33,         // максимум 33ms (30 FPS)
animationThrottle: 1,     // без пропуска кадров анимации
enableHardwareAcceleration: true

// Слабые устройства  
renderInterval: 3,        // каждые 3 кадра (20 обновлений/сек при 60 FPS)
maxDeltaTime: 33,         // максимум 33ms (30 FPS)
animationThrottle: 1,     // без пропуска кадров анимации
enableHardwareAcceleration: true
```

#### Ключевые функции
- `getPerformanceSettings()`: Динамические настройки для разных устройств
- `applyMobileOptimizations()`: Применение CSS оптимизаций
- `autoApplyOptimizations()`: Автоматическое применение при загрузке
