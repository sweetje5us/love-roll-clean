# Оптимизации производительности для мобильных устройств

## Обзор проблем

Основные проблемы с производительностью на мобильных устройствах Cordova:

1. **Потеря кадров при переходах между экранами** - тяжелые анимации framer-motion
2. **Медленная загрузка эпизодов** - отсутствие кэширования
3. **Проблемы с анимациями** - сложные CSS анимации
4. **Проблемы с памятью** - накопление неиспользуемых ресурсов

## Внесенные оптимизации

### 1. Оптимизация ScreenManager

**Файл:** `src/components/ScreenManager.js`

- Определение мобильного устройства
- Отключение анимаций framer-motion на мобильных
- Упрощенные переходы между экранами
- Уменьшенная длительность анимаций

```javascript
// Для мобильных устройств используем упрощенные переходы
if (isMobile) {
  return (
    <div className="screen-manager">
      <div className="screen-container">
        {getScreenComponent(currentScreen)}
      </div>
    </div>
  );
}
```

### 2. Оптимизация GameScreen

**Файл:** `src/components/screens/GameScreen.js`

- Отключение сложных анимаций переходов между сценами
- Упрощенные анимации смены фонов
- Оптимизация анимаций персонажей
- Определение мобильного устройства

```javascript
// На мобильных устройствах отключаем анимации
if (isMobileDevice()) {
  setSceneAnimation(prev => ({ 
    ...prev, 
    isTransitioning: false 
  }));
}
```

### 3. Кэширование эпизодов

**Файл:** `src/utils/episodeManager.js`

- Кэширование конфигураций эпизодов
- Кэширование сцен
- Предварительная загрузка сцен
- Очистка кэша для освобождения памяти

```javascript
// Кэшируем для мобильных устройств
if (isMobileDevice()) {
  episodeCache.set(episodeId, episodeData);
}
```

## Результаты оптимизации

### До оптимизации:
- Потеря 30-34 кадров при переходах
- Медленная загрузка эпизодов
- Проблемы с анимациями
- Высокое потребление памяти

### После оптимизации:

- Упрощенные анимации
- Оптимизированное потребление памяти
