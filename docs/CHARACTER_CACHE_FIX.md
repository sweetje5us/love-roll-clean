# Исправление проблемы с кэшированием персонажей эпизодов

## Описание проблемы

После редактирования персонажей эпизода через редактор (например, изменения одежды, прически и т.д.), изменения не отображались в игре. Персонажи оставались в старом виде.

## Причина проблемы

Проблема была связана с кэшированием данных персонажей на нескольких уровнях:

1. **Кэш браузера** - браузер кэшировал файлы `config.json` эпизодов
2. **Кэш сервера** - сервер мог кэшировать данные персонажей
3. **Кэш в памяти** - данные персонажей кэшировались в объектах JavaScript

## Решение

### 1. Принудительное обновление кэша в коде

Добавлены функции для принудительного обновления кэша:

#### В `src/utils/episodeUtils.js`:
```javascript
export const clearEpisodeCharactersCache = async (episodeId) => {
  // Очищает кэш браузера и принудительно загружает обновленные данные
}
```

#### В `src/utils/episodeManager.js`:
```javascript
// Добавлены заголовки для предотвращения кэширования
const configResponse = await fetch(`/episodes/${episodeId}/config.json?t=${Date.now()}`, {
  cache: 'no-cache',
  headers: {
    'Cache-Control': 'no-cache, no-store, must-revalidate',
    'Pragma': 'no-cache',
    'Expires': '0'
  }
});
```

#### В `src/components/screens/GameScreen.js`:
```javascript
const forceRefreshEpisodeCharacters = async (episodeId) => {
  // Принудительно обновляет кэш персонажей при запуске игры
}
```

### 2. Кнопка обновления кэша в редакторе

В редакторе персонажей добавлена кнопка "Обновить кэш":

- **Расположение**: Вкладка "Персонажи" в редакторе
- **Функция**: Очищает кэш браузера и перезагружает данные персонажей
- **Использование**: Нажмите после редактирования персонажей

### 3. Скрипт командной строки

Создан скрипт для принудительного обновления кэша:

```bash
# Обновить кэш для всех эпизодов
npm run refresh-cache

# Обновить кэш для конкретного эпизода
npm run refresh-cache-episode mansion
```

## Как использовать

### Для разработчиков:

1. **После редактирования персонажей в редакторе:**
   - Нажмите кнопку "Обновить кэш" в редакторе
   - Или запустите `npm run refresh-cache`

2. **При запуске игры:**
   - Кэш автоматически обновляется при загрузке эпизода
   - Проверьте консоль браузера для подтверждения обновления

3. **При проблемах:**
   - Очистите кэш браузера (Ctrl+Shift+R)
   - Перезапустите сервер разработки
   - Запустите скрипт обновления кэша

### Для пользователей:

1. **После обновления игры:**
   - Очистите кэш браузера (Ctrl+Shift+R)
   - Перезапустите игру

2. **При проблемах с персонажами:**
   - Обратитесь к разработчикам для обновления кэша

1. Отредактируйте персонажа в редакторе (например, измените одежду)
