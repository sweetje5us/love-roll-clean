# Система проверки настроения питомцев - Резюме изменений

## Обзор
Добавлена система проверки настроения питомцев (счастье < 60%) для всех способностей. Если питомец грустит, его способности становятся неактивными.

## 🎯 Улучшенная система счастья и энергии

### ⚡ Улучшенное восстановление энергии:
- **Скорость:** 25% каждые 18 минут (быстрее чем раньше)
- **Условие:** Питомец должен спать
- **Логика:** `energyRecovery = (timeSinceSleepStart / 0.3) * 25`

### Как работает шкала счастья:

#### 📉 Убывание счастья:
- **Базовая скорость:** 12% каждые 1.5 часа
- **Зависит от:** Времени с последней игры (`lastPlayed`)
- **Не зависит от:** Состояния сна (в старой версии)

#### 📈 Восстановление счастья:

**1. Во сне (основной способ):**
- **Базовая скорость:** 5% каждые 2 часа (очень медленно)
- **Условие:** Питомец должен спать
- **Логика:** Зависит от других характеристик

**Условия восстановления во сне:**
- **Все характеристики ≥ 70%:** 15% каждые 2 часа (быстро)
- **Голод ≥ 70% ИЛИ здоровье ≥ 70%:** 8% каждые 2 часа (средне)
- **Характеристики < 70%:** 0% (не восстанавливается)

**2. От действий игрока:**
- **Игра с питомцем:** +25% счастья (единственный способ быстрого восстановления)
- **Кормление:** НЕ влияет на счастье (убрано для баланса)
- **Лечение:** НЕ влияет на счастье (убрано для баланса)

#### 🔄 Модификаторы счастья:

**Отрицательные модификаторы (уменьшены для баланса):**
- **Голод < 30%:** -0.3% за каждый % голода ниже 30
- **Здоровье < 50%:** -0.2% за каждый % здоровья ниже 50  
- **Энергия < 20%:** -0.25% за каждый % энергии ниже 20

**Пример расчета:**
```javascript
// Питомец: голод 20%, здоровье 40%, энергия 15%
happinessModifier = -(30-20)*0.3 - (50-40)*0.2 - (20-15)*0.25
happinessModifier = -3 - 2 - 1.25 = -6.25%
```

#### 🧮 Итоговая формула счастья:
```javascript
happiness = Math.max(0, Math.min(100, 
  baseHappiness - happinessDecay + happinessRecovery + happinessModifier
))
```

## Затронутые способности

### 1. Бонусы к характеристикам
- **Где используется:** Окно броска кубика
- **Проверка:** `getPetStatBonus()` с передачей `petState`
- **Результат:** Бонус = 0 при счастье < 60%

### 2. Бонусы к результату броска
- **Где используется:** Окно броска кубика
- **Проверка:** `getPetCubeBonus()` с передачей `petState`
- **Результат:** Бонус = 0 при счастье < 60%

### 3. Переброс кубика
- **Где используется:** Окно броска кубика
- **Проверка:** `canPetReroll()` с передачей `petState`
- **Результат:** Переброс недоступен при счастье < 60%

### 4. Улучшение отношений
- **Где используется:** Специальное взаимодействие "pet_play"
- **Проверка:** `canPetImproveRelations()` с передачей `petState`
- **Результат:** Взаимодействие недоступно при счастье < 60%

## Техническая реализация

### Порог счастья
- **Критический уровень:** 60%
- **Логика:** `petState.happiness < 60`
- **Восстановление:** При достижении 60%+ способности снова активны

### Производительность
- Состояние питомца передается только при необходимости
- Проверки выполняются только при наличии питомца
- Кэширование состояния через `getActivePet()`

### Совместимость
- Обратная совместимость с существующими питомцами
- Опциональный параметр `petState` во всех функциях
- Graceful fallback при отсутствии состояния питомца

## 🎮 Стратегии управления счастьем

### Быстрое восстановление счастья:
1. **Игра с питомцем** (+25%) - единственный способ быстрого восстановления
2. **Кормление и лечение** - НЕ влияют на счастье (убрано для баланса)

### Долгосрочное поддержание:
1. **Уложить спать** - восстановление зависит от других характеристик
2. **Поддержание голода и здоровья ≥ 70%** - для быстрого восстановления во сне
3. **Регулярные игры** - каждые 1.5 часа для поддержания

### Стратегия сна:
- **Все характеристики ≥ 70%:** Быстрое восстановление счастья (15%/2ч)
- **Голод ≥ 70% ИЛИ здоровье ≥ 70%:** Среднее восстановление (8%/2ч)
- **Характеристики < 70%:** Счастье не восстанавливается

### Критические пороги:
- **Голод < 30%:** Влияет на счастье
- **Здоровье < 50%:** Влияет на счастье  
- **Энергия < 20%:** Влияет на счастье
- **Счастье < 60%:** Способности неактивны
